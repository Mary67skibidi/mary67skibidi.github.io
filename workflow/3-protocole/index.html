3. Protocole et Traçabilité

Afin de pouvoir reproduire les mêmes résultats et prouver que rien n’a été altéré, un protocole strict est appliqué.

En plus de chaque fichier créé par scellé comme vu précédemment, on a un fichier appelé “CASE”. Celui-ci ressemble à ça :

[ID DE L'AFFAIRE]

[TABLEAU RETRAÇANT CE QUI EST FAIT SUR CHAQUE SCELLÉ]

[RÉSUME DE L'AFFAIRE FAIT À L'ÉTAPE 1]

Un tableau peut ressembler à ça :

| ID     | Description                | Action                      |
|--------|----------------------------|-----------------------------|
| 01 PIE | Téléphone portable REDMI   | MSAB FSS fait. Analyse faite|
| 02 PIE | Disque dur externe TOSHIBA | Copie faite. Analyse à faire|
|        |                            |                             |

Ainsi, chaque action faite sur un scellé est marquée.
