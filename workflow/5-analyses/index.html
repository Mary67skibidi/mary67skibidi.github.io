5. Analyses

L’étape d’analyse consiste à fouiller la copie du disque ou l’extraction de téléphone pour y trouver des éléments pertinents pour l’enquête.

Ce que j’ai vu pendant mon stage

Après toutes ces préparations, nous sommes prêts à commencer le travail plus “d’enquêteur”. On utilise des outils tels que Forensic Explorer (FEX) et X-Way pour les disques durs, ou le viewer MSAB ou Cellebrite pour les téléphones. En particulier sur les affaires de pédocriminalité, les choses les plus importantes sont dans les images/vidéos et les historiques de navigateur. C’est pourquoi les outils intègrent des moyens de trier les médias via des algorithmes de détections afin de pouvoir filtrer par nudité etc. Bien évidemment, les outils n’ont pas 100% raison donc il faut bien vérifier à la main. On peut aussi rechercher des expressions spécifiques afin de trouver des messages contenant des preuves. Dès que quelque chose de positif est trouvé, on le note dans le rapport et on l’extrait. Comme vu précédemment, le rapport se présente de cette manière :

[SCELLE]

Description : [description, chose importantes à dire]

[TABLEAU DE PHOTOS DU SCELLE EMPAQUETÉ ET SORTI DU PAQUET + CHOSES IMPORTANTES (DISQUE DUR, CARTE SD...)]

Données techniques :
	[CAPTURE DECRAN DES DONNÉES TECHNIQUES]

Données analysées :
	[CAPTURE D'ÉCRAN DES DONNÉES ANALYSÉES, C'EST À DIRE LE NOMBRE DE FICHIERS, LE NOMBRE D'IMAGES ETC]

Analyse :
	[ANALYSE]

Dans les données techniques, on met la capture d’écran du type d’appareil analysé et des comptes utilisateurs. Pour les données analysées, c’est la capture d’écran du nombre de médias, d’app etc Et enfin dans l’analyse chaque chose jugée importante est notée, décrite et expliquée.
